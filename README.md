AnggaranKu — a household budget site (weekly envelope method) for the make.fun bounty "Make the best household budget site". A static, offline-first site: dashboard, weekly cash envelopes, bill calendar, debt payoff tracker and shopping planner, with real figures for an illustrative Indonesian family of four ("Contoh keluarga", Rp8.500.000/month).

## Run it

```sh
python3 -m http.server 8000 --directory app
```

Then open http://localhost:8000 in a browser. No network requests: every file the site loads lives under `app/`.
